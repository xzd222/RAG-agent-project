📋 API 端点一览
方法路径功能说明
GET / 前端页面 StaticFiles 托管 frontend/dist/index.html
GET /api/health 健康检查 返回 {"status":"ok","service":"rag-agent-api"}
POST /api/chat SSE 流式聊天 接受 {query}，返回 text/event-stream
GET /api/documents 文档列表 返回文件名、MD5、入库状态
POST /api/documents/upload 上传文档 Multipart file (txt/pdf)，自动入库
DELETE /api/documents/{filename} 删除文档 从 data/ 目录删除文件
POST /api/documents/reingest 批量重新入库 扫描 data/ 全部文件重新向量化
