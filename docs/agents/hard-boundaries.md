# 硬边界与安全规则

> 违反以下任何一条，代码不可接受。

---

## 密钥与敏感信息

- API Key / Token / 密码 **只能** 存 `.env` 或环境变量
- **禁止** 出现在：代码、配置文件 (YAML)、日志、Prompt、注释
- 代码中仅通过 `os.getenv` 读取
- `.env` 绝不提交到版本库

## 安全

- 禁止用户输入拼接为 shell 命令
- 禁止 Agent 自主执行破坏性文件操作
- 禁止 Agent 未经确认访问外部网络并产生费用
- 外部 API 调用必须显式配置凭证来源和超时

## 异常处理

- 禁止裸 `except:`，必须指定异常类型
- 禁止模块全局静默吞异常
- 异常必须：记录日志 → 向上返回明确错误
- 用户可见错误：简洁描述；开发日志：含完整 traceback

## 日志

- 禁止 `print()` 替代日志
- 统一使用 `utils.logger_handler`

## 编码

- 中文内容统一 UTF-8
- 禁止在 import 阶段执行重型初始化（加载模型、创建向量库、批量读取文档等）

## 数据诚实

- 工具禁止返回虚假数据（Mock 必须在 name/description 中显式标注 `[MOCK]`）
- RAG 信息不足时必须明确拒答或说明信息不足
- Prompt 禁止要求模型编造事实、来源、时间或工具结果

## 提交黑名单

以下内容 **绝不提交**：

| 不提交 | 原因 |
|--------|------|
| `.env` | 敏感信息 |
| `venv/` | 本地环境 |
| `__pycache__/` | 编译缓存 |
| `chroma_db/` | 向量库持久化 |
| `logs/` | 运行日志 |
