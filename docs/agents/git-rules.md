# Git 操作规则

---

## 前置条件

所有 Git 操作都必须先获得用户明确允许。

---

## 操作权限表

| 操作 | 条件 |
|------|------|
| `git status` / `git add` / `git commit` | 用户允许后执行 |
| `git push` / `git pull` | 每次提交/拉取前需用户允许 |
| `git remote` 配置 | 先索取仓库地址，用户允许后配置 |
| `git init` | 项目未初始化时，确认后执行 |
| `git branch` / `git checkout` | 用户允许后执行 |

## 禁止操作

以下操作**绝不执行**，除非用户**明确要求**：

- `git reset --hard`
- `git clean`
- 强制 push (`--force`)
- 删除分支 (`-d` / `-D`)
- 回滚用户改动

---

## 提交规范

- 每完成一个明确步骤 → 一次提交
- 提交信息简洁说明变更范围
- 不把多个无关步骤混入同一次提交
- 每次提交后 → 用户允许下 push
