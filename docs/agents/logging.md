# 日志规范

---

## Logger

- 统一通过 `utils.logger_handler` 创建
- 禁止 `print()` 用于业务日志

---

## 必须记录的关键节点

```
配置加载 → 模型初始化 → 工具调用 → RAG 检索 → 向量入库 → 异常捕获
```

---

## 分层策略

| 层面 | 内容 | 受众 |
|------|------|------|
| 用户可见 | 简洁的中文错误描述 | 最终用户 |
| 日志文件 | 完整 traceback + 上下文信息 | 开发者 |

---

## 禁止

- 正常业务路径中用 `print()` 替代日志
- 日志中泄露 API Key、Token、密码等敏感信息
- 静默吞异常（异常必须落日志）
