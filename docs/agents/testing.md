# 测试要求

---

## 框架

- 使用 `pytest`
- 测试文件放入 `tests/` 目录

---

## 最小测试覆盖

| 测试项 | 验证点 |
|--------|--------|
| 配置加载 | `config/*.yml` 可正确解析，key 存在 |
| Prompt 加载 | 模板文件存在且包含必要变量 |
| 模型工厂 | 按配置创建正确的 ChatModel / EmbeddingModel |
| RAG 初始化 | 向量库连接正常 |
| md5 去重 | 相同文件不重复入库 |
| Tool 调用 | 函数可独立调用且返回格式稳定 |

---

## 触发条件

新增或修改以下内容时，必须补齐对应测试：

- 核心业务逻辑
- 配置文件结构
- Prompt 模板
- Tool 函数
- RAG 链路
