# 配置管理

---

## 配置文件清单

| 文件 | 职责 | 加载策略 |
|------|------|----------|
| `config/agent.yml` | 模型相关参数 | key 缺失 → 启动时报错 |
| `config/rag.yml` | RAG 参数 | 提供合理默认值 |
| `config/chroma.yml` | Chroma + 切片参数 | 提供合理默认值 |
| `config/prompts.yml` | Prompt 文件路径 | 文件不存在 → 启动时报错 |
| `.env` | 敏感信息 (API Key 等) | **不提交**，仅通过 `os.getenv` 读取 |

---

## 约束

### 安全

- 敏感信息 **只能** 放 `.env` 或环境变量
- 代码中仅用 `os.getenv` 读取，不硬编码
- `.env` 绝不提交

### 一致性

- 代码读取的 config key 必须与 YAML 文件中的 key 一致
- 新增配置项需提供合理默认值，或启动时明确报错（含错误原因）

### 存放规则

| 存放 | 不存放 |
|------|--------|
| 模型名、路径、检索参数、提示词路径 | API Key、Token、密码、数据库连接串 |
